# Plan 68 — Install Android NDK in CI (unblock native tunnel builds)

`make compile-cloudflared` (and `compile-ngrok-native`) fail INSTANTLY on every CI run — including
`main` (runs #6/#7) — because `NDK_ROOT` auto-detection finds nothing: GitHub `ubuntu-latest` runners
ship no NDK under `$ANDROID_HOME/ndk`, and no workflow step installs one. This blocks `build-release`
(GMS+FOSS) and `test-e2e` for every PR and for `main` itself. Evidence: step
`Compile cloudflared for Android` fails in 0s on all runs; the Makefile guards print
`ERROR: Android NDK not found` (`Makefile:346-351`, NDK auto-detect `Makefile:326-335`).

**Scope boundary — files this plan may touch (and NO others):**
- `.github/workflows/ci.yml` (add one NDK install step to `test-e2e` and `build-release`)

**Plan document handling:** `docs/plans/68_ci_install_ndk_20261016114000.md` is a tracked, PERMANENT
artifact and MUST be committed as a standalone `docs(plans): add plan 68` commit (repo convention).

## User Story 1 — NDK available before native compiles

**Why:** Without an NDK, `NDK_ROOT` is empty and both native builds exit 1 before compiling anything.
The Makefile itself prescribes the version: `ndk;27.2.12479018`.

**Acceptance criteria:**
- [ ] `build-release` (GMS+FOSS) and `test-e2e` install `ndk;27.2.12479018` via `sdkmanager`
  (present on runners under `$ANDROID_HOME/cmdline-tools/latest`) BEFORE `Compile cloudflared`.
- [ ] The `Compile cloudflared for Android` step starts compiling (runs > 0s) instead of instant-fail.
- [ ] No other job/step modified; no version bumps; caching the NDK is an optional follow-up, not this plan.

### Task 1.1 — Add the install step (both jobs)

Insert after `Set up Gradle`, before `Compile cloudflared for Android`:

```yaml
      - name: Install Android NDK (required by native tunnel builds)
        run: |
          yes | "$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager" --install "ndk;27.2.12479018" > /dev/null
```

- [ ] `git diff main..HEAD --stat` shows ONLY `.github/workflows/ci.yml` + this plan doc.

  instant-fail signature is gone; real failures get their own plan).
