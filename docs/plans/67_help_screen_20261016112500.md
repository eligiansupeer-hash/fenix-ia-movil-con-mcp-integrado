# Plan 67 — In-app Help screen (textual user guide)

Add a self-contained **Ayuda** screen under Ajustes with step-by-step textual guides, so users can
connect web/desktop AI clients without guessing where each setting lives. Motivated by field evidence
(2026-10-16 mission): users cannot discover the tunnel → public URL → override → OAuth-approve flow,
the tunnel toggle fails silently, and quick-tunnel URLs change on every restart.

**Scope boundary — files this plan may touch (and NO others):**
- `app/src/main/kotlin/com/fenix/mobilemcp/ui/navigation/Routes.kt` (add `SettingsRoute.Help`)
- `app/src/main/kotlin/com/fenix/mobilemcp/ui/screens/settings/HelpScreen.kt` (NEW, self-contained)
- `app/src/main/kotlin/com/fenix/mobilemcp/ui/screens/SettingsScreen.kt` (register destination)
- `app/src/main/kotlin/com/fenix/mobilemcp/ui/screens/settings/SettingsIndexScreen.kt` (entry row)
- `app/src/main/res/values/strings.xml` + `app/src/main/res/values-es/strings.xml` (12 help strings each)

**Plan document handling:** `docs/plans/67_help_screen_20261016112500.md` is a tracked, PERMANENT artifact
and MUST be committed as a standalone `docs(plans): add plan 67` commit (repo convention).

## User Story 1 — Help destination wired into Ajustes

**Why:** A single visible entry point (Ajustes → Ayuda) answering: how to connect an AI, stable vs
temporary URL, where each setting lives, safety rules, and what each common error means.

**Acceptance criteria:**
- [ ] Ajustes shows an “Ayuda / Guías paso a paso” row (Help icon) that opens `settings/help`.
- [ ] The screen renders 5 sections (Conectar una IA / URL estable / Dónde está cada cosa / Seguridad /
  Si algo falla) in the active locale (es + en strings, zero hardcoded user-facing text).
- [ ] Back navigates to the Ajustes index; no ViewModel/permission changes; no new dependencies.

### Task 1.1 — Routes, screen, registration, index entry, strings

**Actions:**
1. `Routes.kt`: add `data object Help : SettingsRoute("settings/help")`.
2. NEW `HelpScreen.kt`: `HelpScreen(onBack)` + private `HelpSection(@StringRes title, @StringRes body)`;
   `TopAppBar` with back arrow (`cd_back`), scrollable `Column`, M3 `titleMedium`/`bodyMedium`.
3. `SettingsScreen.kt`: import + `composable(SettingsRoute.Help.route)`.
4. `SettingsIndexScreen.kt`: `Icons.Default.Help` entry row at the end of the list.
5. Both `strings.xml`: `settings_help_title/subtitle` + `help_{connect,stable_url,where,security,trouble}_{title,body}`.
